# Wheel App

An application for Android better than the popular wheeling app.

Wheel App is a native Android decision-maker built with Kotlin and Jetpack Compose. Spin a fully customizable wheel to randomly pick a winner from your own list of options, or flip a coin for quick yes/no decisions — all with a clean, modern interface.

## Features

- **Custom Spinning Wheel** — Add, edit, remove, and color your own wheel slices to build any list you want (raffles, decisions, games, giveaways, etc.)
- **Coin Flip** — A dedicated animated coin flip screen for quick heads-or-tails decisions
- **Save & Favorite Wheels** — Save your wheel configurations and mark favorites for quick access later
- **Spin History** — Automatically tracks past spin results so you can look back at previous winners
- **Sound Effects** — Toggleable sound on spin completion and coin flips
- **Themes** — Switch between light/dark app themes
- **Multi-language Support** — Built-in translation system for multiple languages
- **User Profiles** — Sign in (including anonymous login) to sync your wheels and history
- **Smooth Animations** — Fluid wheel spin and coin flip animations built entirely in Jetpack Compose
